## 我在做的事

### [MoonAI](https://github.com/qinghui316/moonaigc) · 短剧创作 Agent 工作台

把剧本拆解、结构化分镜、AI 生图和素材管理组织到同一个项目里。创作者可以管理角色、场景和道具，回看生成记录，继续编辑已有结果。

我关注长文本拆解、分镜结构和跨阶段的信息衔接，让生成结果能够进入后续制作流程，减少在多个工具之间反复搬运素材与上下文。

### [ECL Harness Engineer](https://github.com/qinghui316/ecl-harness-engineer) · 面向长期开发的 Agent 工程工具

为项目建立共享知识、变更记录和验证流程，让 Agent 理解已有约束，跟进任务，并留下可交接的开发证据。

通过结构化变更与多 Worktree 协作，把需求、实现、审查和验收连接起来；再将经过验证的经验回流到项目知识中，供后续开发复用。

### [Beaver Code](https://github.com/qinghui316/beaver-code) · AI Agent 开发桌面工作台

把项目理解、需求对话、任务执行、验证审查和人工确认放进同一个本地桌面工作台。提供 Agent 直连开发与 AHO 多 Agent 协作两种模式，通过任务编排与 Worktree 隔离组织开发过程，让任务进度、执行证据和需要人工判断的节点更清楚。

我关注长任务的状态管理、失败恢复和人工接管，让人能够看清 Agent 正在做什么，并在关键节点参与决策。
